# Vitrine Empório RSJJ

Sistema web de vitrine digital com todos os produtos do Empório RSJJ, desenvolvido como projeto acadêmico.

## Acesse o projeto
(https://vitrine-emporio-rsjj.vercel.app/)


## Funcionalidades
- Vitrine com 384 produtos organizados por categoria
- Busca por nome ou código do produto
- Filtro por categoria
- Ordenação por nome e preço
- Botões de contato via WhatsApp e Instagram
- Layout responsivo para celular

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
